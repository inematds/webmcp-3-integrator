Use plain JavaScript as a reference

What it is: A framework-free implementation makes registration, dependencies, and cleanup explicit.

Why learn: The reference reduces magic and helps diagnose problems hidden by hooks or dependency injection.

Before modeling

Model an idempotent React hook

What it is: The effect registers tools for the current state, and cleanup aborts the previous registrations.

Why learn: Strict Mode, rerenders, and dependency changes must not duplicate names in the catalog.

Wrap it in an Angular service

What it is: A service receives dependencies, registers the tools, and exposes cleanup to the component or route.

Why learn: Dependency injection keeps rules testable and separate from the visual lifecycle.

Respect the client and server in Next.js

What it is: document.modelContext only exists on the client and after the document is active.

Update tools when changing routes

What it is: SPAs need to remove tools from the previous route and register only the capabilities of the new screen.

Why learn: A stale catalog is stale UI: the agent sees an action that the person can no longer perform.

Simulated failure

Run the scenario with missing state, invalid input, or unavailable capability.

Expected recovery

The response explains what failed, what remains safe, and which action can continue.

Minimum test matrix

✓ reproducible happy path

✓ actionable invalid input

✓ cancellation ends work

✓ fallback preserves the journey

✓ interface reflects the state

✓ backend maintains authorization

Compare implementations using the same test

What it is: Different frameworks must fulfill the same observable contract for registration, execution, UI, and cleanup.

Why learn: A shared matrix separates differences in ergonomics from actual differences in behavior.
